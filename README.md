# EyeTrackingProject

# Steps:

Run Main.py


When the program opens, keep your face centered in front of the webcam.


Press c while looking at the center of the screen to calibrate the eye sphere centers.


Press v while continuing to look at the center of the screen to create the virtual monitor.


Complete the screen calibration by looking at each calibration dot and pressing the matching key:


1 = top-left

2 = top-center

3 = top-right

4 = middle-left

6 = middle-right

7 = bottom-left

8 = bottom-center

9 = bottom-right
